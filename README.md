## Contributing

We welcome all contributions — code, design, docs, or bug reports!

### Getting started

```bash
# Clone the repo
clone https://github.com/gghaoao/opencut-video-editor.git
cd opencut-video-editor

# Install dependencies
pnpm install

# Start the API server
pnpm --filter @workspace/api-server run dev
```

### How to contribute

1. **Fork** the repository
2. **Create a branch** for your change
3. **Commit** your changes with a clear message
4. **Push** to your fork
5. **Open a Pull Request** — describe what you changed and why

### Contribution guidelines

- Keep PRs focused — one feature or fix per PR
- Write clear commit messages following [Conventional Commits](https://www.conventionalcommits.org/)
- Run `pnpm run typecheck` before submitting
- Open an issue first for large or breaking changes

### Reporting bugs

Please [open an issue](https://github.com/gghaoao/opencut-video-editor/issues/new) with:
- A clear description of the bug
- Steps to reproduce
- Expected vs actual behaviour
- Browser / OS / Node version
